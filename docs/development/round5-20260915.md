# agent18 0.5 集成与运行验收

日期：2026-09-15。版本：0.5.0 集成预览。范围是仓库中的真实 HTTP 服务、Docker、PostgreSQL、OPA 与合成 SaaS；不包含接入者生产系统或真实模型供应商验收。

## 本轮交付对应关系

| 用户路径 | 实现内容 | 实际验证 |
| --- | --- | --- |
| 下载后安装 | 可重复初始化、五步向导、完成后进入接入工作台 | 全新临时配置与独立 Compose 项目；显式项目脚本避免与 pnpm 内置 setup/doctor 重名 |
| 接入原有系统 | 项目身份配置、精确 Origin、短期 Token、浮窗/内嵌/独立页 | Alice、同租户 Bob、另一租户 Nina；宿主与独立页身份交接 |
| 导入资料 | 目录/Git、原文/模型构建、草稿审核、发布与撤下、watch、独立项目配置 | 相同签名复用；变化产生草稿；扫描失败前撤销收紧的旧受众；标题与长度参与检索排序 |
| 查询业务 | OpenAPI GET 导入、默认禁用、角色与字段投影、受限请求 | 实际订单 API、对象隔离、隐藏字段、路径限制、超时/响应体预算、OPA 不可用时拒绝 |
| 代办业务 | prepare/execute/status、用户确认、持久化执行状态、业务幂等回执 | 准备阶段不改值；确认后读回变化；重复确认不重复写；未知结果只核对回执 |
| 持续支持 | Case/Run/outbox、客户消息、部署者回复、解决与重新打开 | 客户 → Worker → 引用 → 追加说明 → 支持回复 → 客户确认解决；晚到的 Run 不覆盖解决状态 |
| 维护部署 | 诊断、备份、隔离恢复、显式切换新库、公开部署配置与代理示例 | 真实 pg_dump/pg_restore、新库激活、恢复后客户历史与业务提案仍可读取 |
| 开源交付 | 中英文入口、文档站点、API/配置/标准、贡献指南、问题模板、CI、SDK 导出 | 文档本地链接核对、全部客户路由与 OpenAPI 一致、许可证与 SHA-256 清单 |

## 执行结果

- `pnpm check`：格式、TypeScript、前端与 SDK 构建、单元测试、发布清单通过。单元模式 40 项通过，依赖真实服务的 79 项按设计跳过。
- `pnpm test:integration`：15 个文件、119 项全部通过；此模式包含上述单元测试，不能将两个数量相加。
- `pnpm test:policy`：12/12 项通过。
- `pnpm test:recovery`：3 项实际进程重启与重复执行检查通过。
- `pnpm test:journey`：7 个完整旅程阶段通过，包括新的数据库恢复、显式激活及恢复后的客户数据读取。该脚本使用独立端口、配置和数据卷，并只清理自己创建的资源。
- `pnpm audit --prod --json`：本次审计未报告已知依赖漏洞；结果是本次依赖数据库快照，不代表永久安全。
- `pnpm run doctor --json`：7 项通过、2 项明确警告。未配置真实模型，且保留演示身份；当前本地 readiness 正常。
- 发布清单：22 个客户 API 操作，SDK gzip 8,525 字节，低于 15 KiB 预算。SDK、OpenAPI、MIT License 与校验值导出到忽略目录 `.local/release/`。

本机另对保留历史数据的运行环境做了真实备份恢复演练：恢复后包含 270 个 Case、10 条跟进消息、597 条历史知识条目、101 个业务提案、5 项迁移。无 scope 的应用账户读取问题、消息和提案为零。演练未替换活动数据库；备份含私密配置，留在本地忽略目录，不随代码发布。

## 浏览器效果验收

- 部署工作台：完成初始化后默认进入工作台，显示真实部署健康、接入项目、已启用能力；身份/接口设置与客户收件箱可以使用。
- 独立 SaaS：页面订单和浮窗查询来自同一个实际业务 API。Alice 看到 ORD-1001/1002，Nina 看到 ORD-2001；切换用户会重建助手与身份。
- 独立支持页：验证当前用户查询结果、问题提交、后台处理引用、追加说明、收到支持回复、确认解决。
- 375 CSS 像素有效内容宽度（390 像素测试视口含滚动条）：工作台、客户问题页和文档站点无页面横向溢出。桌面布局同时核对。
- 本地知识样例更新为 52 篇已发布客户文档和 163 篇内部源码条目；引用均有文件及合法起止行号。客户检索展示新文档，并明确标识原文检索模式。

检查中修正了工作台继承旧 main 边距、查询表单原生样式、提示框缺少样式、客户页暴露内部处理代码的问题。

## 证据与边界

本地命令日志保存在 `.local/round5-*.log`，旅程机器结果在 `.local/release/journey.json`。这些忽略文件不进入公开 Git；GitHub Actions 对提交的实际检查结果由 [仓库 Checks](https://github.com/LoganLiu92/agent18/actions/workflows/ci.yml) 记录，成功时上传 SDK/API 与旅程产物。

模型协议、引用校验和错误处理使用可控服务测试；没有实际供应商 Key，不能声称已经完成自有模型联调。业务数据是合成订单与通知偏好，没有发送邮件或办理真实客户交易。实际 SaaS 上线仍需要其身份签发、对象授权、业务桥与 HTTPS 环境验收。

本版不含远程企业管理员 SSO、集群高可用、向量检索、运行日志根因分析或自动代码修复，也没有发布公共 npm 包和预构建镜像。完整机制及扩展边界见 [0.5 运行机制综述](../overview/agent18-0.5-overview.md)。
