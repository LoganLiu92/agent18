# 第四轮研发记录 · 2026-09-15

本轮目标：让 agent18 安装后有可用的初始化流程，为现有网站提供浮窗和独立支持入口，并在界面中说明代客操作如何经过 SaaS 后端执行。

## 交付范围

| 用户诉求 | 实现入口 | 验收证据 |
| --- | --- | --- |
| 安装后逐步配置 | `pnpm start`、4321 `/setup` | 访问码进入、五步配置、模型可跳过、现有配置恢复、Core 应用完成 |
| 代码和文档变成可使用的知识 | 向导来源、构建、分页检查和发布 | 本地文档 5 个文件 / 32 条，内部源码 30 个文件 / 124 条；两类分别发布 |
| 网站浮框入口 | `mountFloatingAssistant`、示例 SaaS `/example` | 浮窗展开/关闭、知识检索、业务预览确认、成功回调；390px 窄屏检查和 Escape 焦点返回 |
| 页面中的嵌入区块 | `mountAssistant`、`/example?mode=inline` | 共享同一 SDK 和隔离样式，保留原挂载 API |
| 独立客户支持页 | `openSupportPage`、Core `/support` | 来自独立 SaaS 的窗口交接，识别 Alice，显示 32 条客户知识，提交本地合成问题成功 |
| 说清代客操作 | 向导执行说明、网站指南、0.4 综述 | 明确为前端预览确认 → Core → SaaS 业务桥 → 当前用户权限校验 → 回执；网页点击执行未实现 |

初始化配置服务不暴露在客户 Core 中。新增模型 Key 保密、Origin/Host/本机/部署访问码校验；来源移除或受众调整会立即撤下旧知识，受众变化后不能从向导发布旧权限版本。修复旧初始化脚本在升级失败时可能重新初始化密钥的问题，并验证全新安装预置的演示来源 Origin 和业务桥可用。现有 `.local` 数据、密钥、历史任务与业务记录保留。

## 自动验证

- `pnpm format:check`、TypeScript 检查、Vite 构建通过。
- `pnpm test`：35 项单元/边界测试通过。
- `pnpm test:integration`：104 项测试通过，包含上述 35 项及 69 项集成测试，使用真实本地 PostgreSQL、OPA 和合成业务。
- `pnpm test:policy`：12 / 12 通过。
- `pnpm test:recovery`：API 关闭后 Case/Run/outbox 保留；重启 Server/Worker 后原 Run 完成；重复执行不增加证据或审计，3 项检查通过。
- SDK + 浮窗构建继续受 15 KiB gzip 预算约束。

新增测试覆盖部署配置边界、密钥不回显、连接测试不修改配置、私钥拒绝、固定应用操作、重启失败结果、初始化失败保留旧身份、全新演示配置、知识构建/发布/撤下和客户受众过滤，以及独立页消息的窗口/Origin/channel/project 绑定及弹窗失败清理。

## 浏览器与运行证据的边界

在本地部署中完成向导配置并实际重新创建 Core，`/public/installation` 返回 `setupCompleted: true` 和 `version: 0.4.0`。配置文件没有提交到仓库。客户支持页只读到 32 条客户文档；124 条内部源码由部署者检查，不出现在客户目录。

浮窗使用示例 SaaS 的 Alice 身份确认关闭邮件通知偏好，收到持久化成功回执，并通过回调在原页面显示结果。该示例只保存偏好，不发送邮件。独立支持页提交了明确标记为本地合成验收的问题，并在当前用户记录中看到它。知识检查分页可访问 1–50、51–100 和 101–124 条。

没有真实供应商 API Key，因此真实模型整理与答案质量尚未验收；模型连接和错误路径使用可控测试响应。没有真实客户 SaaS、生产流量、浏览器自动点击或生产业务写入验收。知识源主动构建，无后台定时同步；配置服务为宿主机本地维护入口。

架构与接入说明见 [0.4 综述](../overview/agent18-0.4-experience.md)、[安装向导](../guides/installation.md) 和 [SDK 集成指南](../guides/integration.md)。远程 CI 结果以 GitHub 对应提交的实际运行状态为准。
