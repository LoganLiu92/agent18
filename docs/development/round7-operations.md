## 新增边界与失败用例

- Loki 固定项目、可信 tenant / 可选 subject / trace 条件；返回跨 scope 标签、时间或文本不匹配时拒绝。配置变化、缺少凭据、重定向和过大响应不会返回伪造的正常结果。
- HTTP 只保留状态与耗时，不保存正文。Prometheus 空向量、NaN/Inf、过期样本为未知；第 40 个序列异常仍影响最终状态，不会因展示上限误报正常。
- Case 与捕获/排查任务同事务，重复请求只登记一次。另一用户不能读捕获内容，客户没有内部观测工具权限，也收不到完整工程日志。
- 持久任务的租约恢复、重复告警合并、未知不关闭、健康恢复、工具撤销不发布晚到报告。不同 Core 项目配置互不领取或取消对方任务。
- 模型契约测试使用合成模型：有效 Evidence ID 可以进入报告，虚构引用回退规则；输入只有有界证据摘要和页面错误，无截图。真实供应商的连接与质量仍需接入验收。
- Owner 配置按项目绑定、拒绝 scope 标签覆盖，跨项目报告不可见；幂等请求返回同一个任务 ID。凭据不会在响应里返回，保存权限为 600，非法环境变量名与注入字符被拒绝。

## 浏览器复验

在示例网站触发业务异常，通过右下角单一对话入口提交。预览包含页面文字、错误、失败资源状态与 JPEG；已保存截图保留页面布局，排除助手本身、表单选择器及 `data-agent18-private` 的 `PRIVATE-CAPTURE-CANARY`。Core 保存后，Owner 可以打开同一截图并查看关联的真实 Loki 日志及指标。

工作台已验证数据源表单、配置校验、三类检查结果、异常接手入口、报告和内部知识草稿生成。无效 JSON 会禁用保存；390 像素宽度下表单变为单列，未出现横向页面溢出。草稿未自动发布。截图是经过裁剪与清洗的 DOM 渲染，不是完全无损屏幕录制，未覆盖任意客户页面/浏览器组合。

验证发现并修正了截图移除样式、跨 Core 领取范围和 Owner 幂等回放缺少任务 ID 三处问题，相应流程重新通过。所有数据库记录和日志样本均为本地合成测试；备份、密钥、原始报告与测试数据库不进入 Git。
