## 本轮实现

| 开发包 | 实际改动 | 当前边界 |
| --- | --- | --- |

| A01 基础 | migration 010、独立账号/成员/会话/限流/审计；本地首位管理员初始化；后台登录与工作人员管理页面 | 未部署；浏览器交互与视觉验收待完成，不标记正式可用 |

账号由 Agent18 自己管理。宿主员工 OIDC/SSO 不参与首轮，网站客户继续使用原 Support Token。新增员工 API 位于 `/operator/*`，后台页面入口为 `/admin`；本地 Owner 入口负责初始化，不能用客户身份替代员工会话。

密码哈希使用 scrypt；服务端存会话 Token 哈希，浏览器使用 HttpOnly Cookie；写入要求同源和 CSRF。首次改密、停用、重置密码、权限变化及退出均处理会话失效。保护最后一位启用管理员，账号写入在事务内复核管理员及会话状态。

完整账号恢复入口、审计浏览、分页筛选、逐个知识/工单 API 的权限接入属于 A02 及对应后续开发包。现有项目角色基础不能视为整个未来平台的权限验收已经完成。

## 本轮验证

- `pnpm check` 通过：格式、文档、类型、Console/SDK 构建、72 项普通测试及发行产物检查；104 项集成测试在该命令中按配置跳过。
- 另用隔离数据库执行 5 个针对性测试文件，共 53 项通过，覆盖账号集成、知识索引、实体上下文、provenance 与基础集成；新数据库应用 001—010 迁移成功。
- 账号场景覆盖本地初始化、重复初始化拒绝、同源/CSRF、客户与员工身份隔离、首次改密、授权、最后管理员保护、停用/重置/会话过期及审计凭据排除。
- 临时验证数据库与配置按运行清理；未对活动 Demo 应用新迁移。完整现网升级、浏览器操作、目标成熟网站与真实业务验收均未执行。

53 项包含与普通测试重合的项目，不能将两组数字相加作为独立测试总数。本轮也没有重新执行全部集成、恢复、journey 或 observability 验证。
