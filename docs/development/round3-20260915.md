# 第三轮研发：知识构建、网站接入与业务助手

版本：0.3.0 开发预览，2026-09-15。

## 交付内容

- 新增知识构建包：目录/Git 配置、只读扫描、敏感内容过滤、文件与行号分块、原文/模型两种模式、六类知识目录、模型缓存、版本构建、审核导出、显式发布、回滚及撤下。
- 新增 OpenAI 兼容模型适配器：部署端 BYOK、JSON 输出校验、引用校验、限时/限量、带引用问答、注册业务操作规划。没有模型时保留原文检索与表单操作。
- 新增业务提案状态机：预览、5 分钟期限、用户确认、注册表/角色复核、OPA、单次执行领取、持久结果、不确定状态与回执核对。
- 新增独立 SaaS 业务示例：只修改当前用户自己的通知偏好；SQLite 业务数据和回执同事务提交，版本冲突拒绝。
- 新增网站集成：项目/公钥/租户注册 CLI、按项目 Origin 的 CORS、SDK 分发、可选嵌入面板、独立 SaaS 嵌入示例页面。
- Console 新增知识目录、文章来源、问答与业务助手、最近操作、确认和回执界面；状态说明根据当前配置显示。
- 新增 migrations 003/004，setup 可对原配置做增量升级；既有 PostgreSQL 数据、用户密钥与原有迁移不变。
- 更新 README、贡献/安全说明、完整机制综述、三份接入指南，增加 GitHub Actions 检查定义。

知识原文分块修正了 fenced code block 中的 Shell 注释误当成 Markdown 标题的问题。测试模型缓存使用独立标识，避免持久缓存使重复测试跳过预期的模型验证。

## 验收边界

本轮未提供真实模型 API Key，因此模型 HTTP 合同和知识生成/规划链使用本地测试服务或测试适配器验证，不能声称已验收真实供应商模型质量/费用/配额。SaaS 写入验证是独立本地示例，不代表用户的正式业务接口已接通。

GitHub Actions 文件已配置，远程运行状态需以仓库实际检查为准。尚未发布 npm 包、公共镜像或生产部署。知识扫描/发布目前由部署者 CLI 触发；未实现向量检索、内置增量调度器、日志调查、多步自动业务工作流、任意网页点击或代码修复 PR。

完整运行机制见 [0.3 综述](../overview/agent18-0.3-mechanism.md)。
