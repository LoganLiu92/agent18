# 第二轮研发：持久化 Run 生命周期

日期：2026-09-15；版本：0.2.0。当前为本地 M0 开发版本，未发布远程仓库、npm 包或公共镜像。

本轮解决调查无法取消、重试缺少边界、缺少执行历史，以及队列失败后 Run 可能长期挂起的问题。完整机制见[综述正文](../overview/agent18-overview-20260915.md)与[Word 版](../overview/agent18-运行机制与实现综述-20260915.docx)。

## 实现与证据

| 改动 | 实现入口 | 验证 |
|---|---|---|
| 取消及迟到结果保护 | `packages/application/src/runs.ts`、cancel API / SDK / Console | 等待中取消、同实例信号、跨实例迟到结果、已完成不可覆盖 |
| 有限尝试与手动重试 | 同上；迁移 `002_run_lifecycle.sql` | 每 Run 3 次；每 Case 3 个 Run；并发幂等、父子关联、key 冲突 |
| 持久化执行历史 | `core.run_steps`、Case detail、Console | 步骤范围隔离、应用不可修改 / 删除、事件同时间稳定排序 |
| Provider 有界等待 | `packages/application/src/gateway.ts` | 不响应取消的 Provider 也不会无限阻塞等待；不等同物理终止 |
| 队列失败核对 | `packages/application/src/dispatch.ts` | 真实 pg-boss 查询 + 合成 failed Job；不与执行中的 Run 竞态 |
| 原有安全和恢复链路 | 现有 tests 与 `scripts/verify-recovery.ts` | JWT / RLS / OPA / 输出检查 / 原子 outbox / 重启与重复消费 |

迁移 002 已应用，001 未改写。保留数据库卷及旧 Case；旧历史缺少 steps 时不伪造回填。只增加客户 Run 控制，不引入外部写操作。

## 验收结果

- `pnpm build` 通过：严格类型检查、Console、SDK。Headless SDK 2,057 bytes，gzip 944 bytes（macOS）/ 945 bytes（Linux 镜像）；不包含 Widget。
- `pnpm test:integration`：65 / 65，通过 7 个测试文件；包含 18 个基础测试和 47 个集成测试，其中本轮新增生命周期测试 16 项。
- `pnpm test:policy`：6 / 6 Rego 测试。应用和策略合计 **71 项**。
- `pnpm test:recovery`：3 项断言通过，覆盖 outbox 跨进程存活、重启恢复原 Run、重复完成不重复写证据 / 审计。
- 浏览器实际验收 Case 前缀 `aa460596`：停止本项目 Worker，提交合成问题并取消；重新调查后恢复 Worker；旧 Run 保留取消事件，新 Run 完成 1 次尝试、4 条步骤和 2 条引用。Worker 已恢复运行。
- 排序回归发现 PostgreSQL `now()` 在同一事务中相同，已为步骤查询加入工作流顺序的 tie-break；修复后 65 项应用测试再次通过。
- `pnpm format:check` 与最终 `pnpm typecheck` 通过；`/health/ready` 返回数据库已连接、策略已加载。
- 综述 Word 共 11 页，已渲染并逐页检查；正文、10 张表和当前执行链路图无缺字、裁切或溢出。仓库同时保留 Markdown 正文与可编辑 draw.io 图源。

队列耗尽验证通过对自身合成 Job 注入 failed 状态触发，未声称真实 broker 已运行完所有重投。Provider 使用合成资料或受控故障实现；无真实模型、业务系统、运行时、Git / PR 或生产验收。

## 当前边界与下一步

M0 整体仍未结项。下一步继续验证真实只读 SaaS 接入合同、知识来源权限、远程 JWKS 与集成配置，再推进 ModelProvider / Conversation / 人工接管。Run 取消不能替代远程 Sandbox 资源回收；只读重试不能直接迁移为外部写操作重试。
