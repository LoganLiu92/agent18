## 真正执行过的链路

**真实模型知识流程。** 使用当前 Agent18 权限源码及账号运维说明，两类目录来源生成内容指纹快照，形成 9 段固定证据。独立 Ollama 运行 `qwen2.5:7b`（Q4_K_M，digest `845dbda0ea48ed749caafd9e6037047aa19acfcfd82e704d7ca97d631a0b697e`）。成功主题调用记录 5,030 tokens，约 60.4 秒。初次 60 秒预算明确返回超时；调整有界配置后成功，未绕过任务失败记录。

模型返回一篇配置层草稿并保留缺口。工程复核发现账号删除、会话持久化及恢复后强制改密等无依据表述，正式提交后退回，按实际源码/说明修订，再审核发布内部版本。客户稿从已审核内部稿独立衍生，去除内部源码位置，独立审核发布。20 题构成为概念 5、规则 5、操作 5、API 3、不可回答 2；候选检索与发布检索均 20/20，附逐题工程语义复核。不得将此结果描述为“模型初稿准确率 100%”或外部客户验收。

客户问答接口另以同一真实模型运行 3 道已发布知识问题，均返回正确答案及公开引用（约 8.7—17.7 秒）；无匹配资料的问题返回无答案、无引用。浏览器已验证刷新恢复历史消息及原始引用时间，恢复不执行旧提案。

**真实协议。** HTTPS Git 测试使用临时证书、真实 Git HTTP backend 和只读认证，验证 clone/fetch、commit 与无秘密持久化。Tempo 使用实际 `grafana/tempo:3.0.0` 镜像，OTLP 注入后经正式适配器获取 span，并验证缺失 trace 为未知。外部工单服务用提交后丢回执再重试验证只形成一次外部记录；回写测试覆盖签名、重复、旧版本和回环。销售/网站分析通过独立 HTTP 与 SQLite 权威查询对账，样本明确为合成，不代表接入方财务或流量数据。

**正式页面。** 隔离管理员完成经营 Playbook 参数确认、按门店查询、报告保存、定期报告触发及成功回读；查看可信部署空态、知识主题/固定原文/文档覆盖，保存开发环境验收记录。此前已验收工单回复/内部备注/解决/知识回流/重开和客户持续对话。本轮没有对外发布或发送客户消息。

**恢复与部署。** 隔离数据库执行所有迁移和权限/失败/恢复测试；真实备份恢复覆盖旧结构升级、员工会话撤销、删除账本及新引用擦除。独立 Docker 镜像运行十步接入流程：初始化、重启、配置替换、来源发布、跨租户业务查询、确认写入与回读、Worker 调查与工单、备份、隔离恢复及显式激活后继续处理。保留原活动 PostgreSQL 和既有服务。

本机只读工作空间接口的补充样本为 40 次请求、并发 8，总耗时 77 ms，p50 10 ms、p95 40 ms。它是回环地址、合成管理员、小型数据库的观测值，不是生产容量承诺。

## 验证中修复的问题

- 金额结果同时显示原始单位和币种，避免将美分误标为美元。
- 外部分析请求移出员工权限事务，允许请求执行期间及时撤权；返回后重新验证，撤权后不保存或返回报告。
- dotenv 与 JSON 的转义规则不同；所有新增凭据文件通过精确往返验证序列化，私有 Git 多次保存/撤销不破坏 JSON 绑定。
- 合并主题的证据可重新确认；重复操作受版本锁保护。
- 高优先级发布验证候选标题、正文、类别指纹及最后语义复核，不能用旧成功记录放行新内容。
- Tempo 扩展使用观测工具 v2 与 provider 1.1.0；迁移仅升级原装绑定，保留撤销状态和既有证据，人工修改过的注册项继续要求显式审核。实际网关回归覆盖注册、策略、排查任务及工程证据。
- 历史引用随对话删除及备份删除重放擦除；恢复展示不触发业务写操作。
