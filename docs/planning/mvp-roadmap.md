# 项目状态与路线图

以 [0.5 运行机制综述](../overview/agent18-0.5-overview.md)和当前可执行代码为准。旧版综述保留为历史记录，不代表现版本缺口。

| 阶段 | 状态 | 内容 |
| --- | --- | --- |
| 可信支持基础 | 已实现 | 项目/租户/用户身份、RLS、OPA、Case/Run、outbox、持久审计与恢复 |
| 代码与文档知识 | 已实现 | 目录/Git、受众、原文/模型条目、引用、草稿审核、版本发布、watch |
| 网站接入体验 | 已实现 | 初始化向导、浮窗、内嵌、独立页面、SDK、独立 SaaS 示例 |
| 当前身份业务能力 | 已实现 | OpenAPI GET 导入、角色与字段投影、业务预览/确认/回执 |
| 支持与自托管闭环 | 已实现 | 问题补充/回复/解决、接入工作台、诊断、备份恢复、文档与接口交付 |
| 企业接入扩展 | 待实现 | OIDC/JWKS 自动轮换、管理 SSO/RBAC、全局配额、密钥托管、多实例 HA |
| 成熟知识连接器 | 待实现 | 外部向量检索/知识 provider、成熟解析器、网站/PDF/OCR 适配 |
| 运行时调查 | 待实现 | 审核过的日志/指标/Trace 只读工具、W3C 上下文与 OTel 适配 |
| 代码修复 | 待实现 | 编码代理适配、隔离工作区、分支和 PR、人工审核；无自动生产部署 |

后续能力按独立可运行适配器交付，每项需要真实或明确模拟的验收场景。不会把未连接的工具目录、界面按钮或预留接口描述成已经完成的系统能力。
