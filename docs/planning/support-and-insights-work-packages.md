**支持闭环**

| 编号 | 交付 | 依赖 | 核心验收 |
| --- | --- | --- | --- |
| S01 | Conversation/Message/CaseLink 持久化、客户历史与恢复 | F01、A01 | 刷新/断网重试/多标签页不丢序、不重复消息；跨用户不可读 |
| S02 | 五类保留策略、删除对话/附件、内容脱敏 | S01；与 S01 同批开放 | 删除传播到索引/缓存/历史引用；审计独立；恢复备份不复活已删除内容 |
| S03 | 客户“我的工单”、上报转工单与公开进展 | S01、S02 | 一次上报一个 SUPPORT_TICKET；客户只能读取获准工单及公开消息 |
| S04 | 员工队列、上下文摘要、分配、公开回复/内部备注、状态转移 | S03、A02 | API 与数据授权隔离；并发接手冲突；调查完成不自动解决工单 |
| S05 | 解决方案、重开与知识候选生成 | S04、K05 | 生成内部候选不自动发布；客户版独立审核；重开触发知识复核 |
| S06 | 团队队列、站内通知与基础 SLA | S04 | 工作时间/时区、等待暂停、重开/升级可核对；通知不会越权 |
| S07 | 一个外部工单/通知系统同步 | S04；按真实需求启用 | outbox 投递、签名、去重、乱序、回环与重放验证 |

S01 的历史对话只保存必要消息与结果引用，查询历史标注原查询时间，恢复界面不能再次发送已确认写操作。长对话的模型上下文采用有预算的摘要和选取，不能将所有旧业务结果永久带入模型。

S03/S04 的工单详情固定分为：身份与业务上下文摘要、公开沟通、内部调查、解决方案。顶部展示 tenant/customer、page/entity、businessEvent、requestId/traceId、环境与版本；未提供或未验证的值明确标记。客户端上下文永远不承担授权作用。

SLA 不作为第一版工单阻塞项。先定义状态转移：新建 → 处理中 → 等待客户/内部 → 已解决 → 已关闭，允许获准重开；记录操作人、理由和时间。客户状态映射可以简化，但不能错误展示内部处理内容。

**知识持续维护与运行调查**

| 编号 | 交付 | 依赖 | 核心验收 |
| --- | --- | --- | --- |
| L01 | 来源变化到 Topic/文档的影响列表 | K01—K05 | 变更证据可解释；不把未部署代码变化称为线上知识过期 |
| L02 | 知识缺口与明确规则冲突队列 | L01 | 同概念/同版本/同范围才比较；管理员裁决，模型不自动选边 |
| I01 | 工单到既有日志/指标/Run 的统一证据视图 | S04 | 每条证据有来源、观察时间、范围及验证状态；客户只读安全摘要 |
| I02 | 一个实际 Trace 后端适配 | I01；按接入需要 | 已知请求关联 span；无权限/过期/采样缺失均正确拒绝或显示未知 |
| I03 | 可信部署到源码映射与调查结论分级 | I01、L01 | 使用事故发生时版本；区分假设、已核实原因和待补证据 |

I02/I03 可以在 Insights 首场景之后实施，不能成为无必要的依赖。未验证根因时仍允许记录临时处理方案，但不能由模型自动宣布根因已证明。

**Insights**

| 编号 | 交付 | 依赖 | 核心验收 |
| --- | --- | --- | --- |
| E01 | MetricDefinition/MetricResult/Insight 合同及指标目录 | F02、现有 Tool/Policy | 指标口径版本化，单位、时区、过滤和允许维度明确 |
| E02 | 一个真实只读分析工具 | E01 | 最少三个问题与权威统计对账；未授权维度/租户拒绝 |
| E03 | 提问、参数确认、趋势报告、保存与受控导出 | E02 | 数值确定性计算；证据、查询时间、缺失/截断说明完整；保存后仍重验权限 |
| E04 | 定期报告、暂停、重试和通知 | E03、共享调度与预算 | 不存客户短期 Token 作为长期凭据；撤权暂停；重复触发不重复有效任务 |
| E05 | 经过确认的建议行动 | E03、现有 ActionProposal | 查看分析不产生写入；对象/参数/审批与回执可回读 |
| E06 | 基于至少两个实际场景的 Playbook 抽象 | E02—E04 两个场景实证 | 仅提取已证明的复用部分，不新增自由工具执行权限 |

首个场景选择网站转化或经营表现之一。网站转化要区分用户、会话、事件和转化窗口；经营指标要明确实收/应收、取消/退款、币种、归属门店及比较周期。不能将两类口径混为“业务增长”。

任何“为什么下降”的解释都须关联可见数据；数据不支持时只能提出待核实假设。模型不计算权威金额，不获得任意 SQL；数据源没有可靠隔离或指标定义时，先完成适配，不用管理员凭据绕过用户范围。

**正式运行的共用门槛**

R01 自身遥测与容量/成本预算；R02 可重复发行与升级/回退；R03 保留删除和凭据生命周期；R04 单机恢复或实际承诺的多实例验证；R05 目标系统接入报告。它们随相应功能同步推进，不在发布前临时补齐。

账号、知识、工单、分析分别有测试账户与固定数据样本。测试报告明确运行环境、版本、允许/拒绝/未知/恢复路径、数据回读结果和未验证项。功能完成后才在公开能力表升级状态。
